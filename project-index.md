## Migration gate

Before any consolidation:

1. inventory branches, history, licenses, data, and secrets;
2. define the canonical destination;
3. preserve unique material with provenance;
4. validate the destination;
5. add a source-repository redirect;
6. archive the source;
7. delete only a verified empty duplicate with explicit approval.
